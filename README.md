# GWapprox

Simulation code to accompany 

_On a conjecture of Roverato regarding G-Wishart normalising constants_

Ching Wong, Giusi Moffa and Jack Kuipers (2025), [doi:10.48550/arXiv.2503.13046](https://arxiv.org/abs/2503.13046)

### GWnorm package

The code relies on the [_GWnorm_](https://CRAN.R-project.org/package=GWnorm) R package, whose latest version includes the approximations developed in the manuscript above, along with the Monte Carlo approach developed in [doi:10.48550/arXiv.2404.06803](https://arxiv.org/abs/2404.06803) for comparison.

### Simulations

The main simulations run from the file `comparison_sim.R`, with the simulations results stored in the **sim_results** folder and plotted in the **plots** folder.
